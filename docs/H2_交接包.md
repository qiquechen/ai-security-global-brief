## 二、两个接口契约（最重要，先看懂再写）

### C2：数据库表（已由 H1 在 `ai_digest/db.py` 定义）

写入方式：调用 `db.insert_article(conn, source_id=..., url=..., title=..., published_at=..., text=...)`。
表结构（字段含义）：

| 字段 | 说明 | 要求 |
|---|---|---|
| id | 自增主键 | 库自动生成 |
| source_id | 来源标识 | **必须等于 sources.json 里该源的 id**，否则 H1 附不上机构名 |
| url | 原文链接 | 唯一，重复抓自动忽略 |
| title | 标题 | 原文标题 |
| published_at | 发布时间 | ISO：`YYYY-MM-DD` 或 `YYYY-MM-DDTHH:MM:SS` |
| crawled_at | 抓取时间 | 自动填，可不管 |
| text | 正文 | **清洗后正文全文**（去导航/脚本/广告） |
| dedup_hash | 去重哈希 | 可留空（url 已唯一） |

**关键**：下游筛选需要 `title / url / published_at / text` 四个字段齐全，正文别只存一段摘要，尽量存全文（筛选和摘要都用它）。

### C1：源清单 `config/sources.json`

每条源字段：

```json
{
  "id": "aisi_uk",
  "name": "UK AI Safety Institute (AISI)",
  "country": "UK",
  "type": "gov",
  "method": "page",
  "homepage": "https://www.aisi.gov.uk/",
  "feed": "",
  "enabled": true
}
```

- `id`：小写英文唯一标识，**与入库的 source_id 一一对应**；
- `method`：`rss`（有 feed 用 RSS）/ `sitemap`（有 sitemap.xml）/ `page`（解析新闻列表页，最费工）；
- `feed`：RSS/sitemap 地址（`page` 源可留空）；
- `enabled`：是否启用。

已预置：aisi_uk / cisa_us / ncsc_uk / gmu_nsp / csis / rand 六条示例（首页地址正确，抓取方式待你核实）。**媒体类（NYT、经济学人等）有付费墙，正文抓不全，第一版接受"只取标题+摘要"，正文以智库/官方源为主**——这条口径 H1 已确认。

## 三、抓取实现要点（见 `adapters_template.py`）

- 代理：`.env` 的 `PROXY`（H2 自己填 v2rayN 本地端口），模板已封装 `http_get()`；
- RSS：`feedparser`；sitemap：正则提取 `<loc>`；页面：`BeautifulSoup` 解析列表页拿文章链接，再逐个抓正文；
- 正文抽取：`trafilatura`；
- 限速：每条间隔 ~0.3s，别高并发硬爬（源站会封）；
- 增量：记录每个源上次抓到的 URL/时间，二次运行只抓新增（去重靠 url 唯一即可兜底）。
