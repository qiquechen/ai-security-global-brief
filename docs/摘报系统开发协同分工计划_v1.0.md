# 智能信息摘报系统 · 开发协同与分工计划 v1.0

> 适用范围：两人（H1、H2）+ AI 助手（Claude）协同开发"境外AI安全治理信息每日摘报"系统。
> 目标节奏：今晚出首版样稿 → 3 天内部试运行 → 下周正式上线。
> 前提技术栈：Python + SQLite + feedparser + trafilatura + DeepSeek API + python-docx + SMTP。

## 2. 共享接口契约（先定这 5 样，避免两半打架）

两边并行开发的前提是接口先冻结。以下契约由 AI 起草、双方确认后各自遵守：

### C1：源清单 `config/sources.json`
每源一条：`{id, name, country, type(thinktank/gov/media), method(rss/sitemap/page), url, homepage, enabled, category_hint}`。
属 H2 维护；H1 可提加源需求（如 4 个政府源 + 白宫）。

### C2：数据库表结构（SQLite `data/app.db`）
`articles` 表字段固定：`id, source_id, url(UNIQUE), title, published_at, crawled_at, text, link_hint, dedup_hash`。
H2 负责写；H1 只读。**任何改表需求走 AI 统一协调**，避免两边都改 schema。

### C3：环境配置 `.env`（不入 git，用 `.env.example` 占位）
`DEEPSEEK_API_KEY`、`SMTP_HOST/PORT/USER/PASS`、`RECIPIENT`、`PROXY_PRIMARY/PROXY_BACKUP`（兼容旧 `PROXY`）、`REPORT_CUTOFF_HOUR=6`、`DELIVERY_HOUR=7`。
H1 管 SMTP/收件/DeepSeek；H2 管 PROXY；双方各自填自己的，永不提交真实值。

### C4：LLM 判定与摘要的输入输出 JSON
- 判定函数输入：单篇文章 `{title, source_id, published_at, text摘要前若干字}`。
- 判定输出：`{"in_scope": true/false, "category": "A~H", "importance": "high/med/low", "reason": "一句话理由"}`。
- 摘要输出：`{"zh_title", "source", "date", "url", "points":[3条以内], "facts":[], "note":""}`（≤500字）。
由 H1 起草格式，AI 定稿；H2 只需保证入库字段能喂给该函数，不需要理解判定逻辑。

### C5：调度约定
采集每小时一次（H2 侧）；出报每日北京时间 6:00（H1 侧模块），5:45 触发"昨日 6:00–今日 5:59"查询 → 生成 → 6:10 前发信。

## 4. 交互与配合规范

- **git 分支**：`main` 只放可运行版本；`feat/ingest`（H2）、`feat/report`（H1）各自开发；合 main 前跑一遍最小链路。
- **报错提交流程**：谁遇到报错，按固定格式贴到共享文档：`环境(OS/Python版本) + 执行的命令 + 完整报错`。涉及真实数据的脱敏处理。
- **接口变更**：任何人觉得要改 C1–C5，先在群里说"要改契约 X"，AI 评估影响面后统一改，禁止私自改表结构/prompt 契约。
- **不要互相等**：H2 不必等 H1；H1 用 WP1 导出的样例文件即可开发，不必依赖 H2 的实时库。
- **口径反馈流转**：对接人对 v0.9 口径第 7 节的答复 → H1 转给 AI → AI 改口径并同步影响评分卡 → 通知 H2 是否需要调整采集分类提示。

## 6. 风险与注意

- **机器常开问题（最要紧）**：摘报要每天 6:00 自动出，必须有一台到点开机的电脑。你们现在用自有设备，建议选定一人（通常管采集的那台）试运行期间保持开机；若做不到，需讨论错峰方案或提前把出报时间逻辑做成"开机即补跑"。
- **VPN 断线**：境外源抓取依赖三毛机场；断线会静默失败，日志里要有"连续 N 次失败"告警。备用节点提前配好。
- **媒体付费墙**：NYT/经济学人等正文抓不全，第一版接受"只取标题+摘要"，正文以智库/官方源为主。
- **翻译质量兜底**：DeepSeek 先行；模型抽象层已预留，若试运行发现关键误译，可无缝切 Claude/OpenAI。
- **口径不确定就先不纠结**：第 7 节答复影响"收什么"，不影响"系统能不能跑"，别让它阻塞今晚样稿。
